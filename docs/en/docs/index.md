# Monkay Documentation

Monkay helps Python libraries and applications manage:

- lazy imports with caching controls,
- settings loading and temporary overrides,
- extension registration and ordering,
- context-isolated mutable state via cages,
- ASGI lifespan setup/shutdown integration.
